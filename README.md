# Transaction Master

**Transaction Master** — Python-приложение для анализа банковских операций из Excel-файла, формирования JSON-данных для веб-страниц, подготовки отчётов и получения дополнительной финансовой информации через внешние API.

## Описание проекта

Проект разработан как курсовая работа по Python и демонстрирует работу с реальными данными банковских операций: загрузку транзакций из Excel-файла, обработку данных, расчёт расходов, кешбэка, популярных категорий и формирование отчётов.

Приложение разделено на несколько логических блоков: главная страница с агрегированной информацией по операциям, сервисы для поиска переводов, отчёты по категориям расходов и вспомогательные функции для работы с данными, настройками и внешними API.

Проект показывает навыки декомпозиции бизнес-логики, работы с табличными данными, написания тестов, логирования и организации Python-проекта.

## Основной функционал

- Загрузка банковских операций из Excel-файла.
- Обработка транзакций с использованием `pandas`.
- Формирование данных для главной страницы:
  - приветствие в зависимости от времени суток;
  - расходы по картам;
  - расчёт кешбэка;
  - топ-5 транзакций по сумме;
  - курсы валют;
  - стоимость акций.
- Формирование отчёта по тратам в выбранной категории за последние 3 месяца.
- Поиск переводов физическим лицам по описанию операции.
- Настройка пользовательских валют и акций через JSON-файл.
- Логирование операций и ошибок.
- Покрытие бизнес-логики тестами с использованием `pytest`.

## Установка:
1. Клонируйте репозиторий:
```
git clone https://github.com/newfatto/transaction_master.git
cd transaction_master
```
2. Установите зависимости:
Если используется Poetry:
```
poetry install
```
Активировать виртуальное окружение
```
poetry env activate
```
3. Создайте файл .env на основе .env_template и заполните необходимые значения.
```
cp .env_template .env
```
В .env могут храниться API-ключи для внешних сервисов.

4. Подготовить данные
В директории data/ должен находиться Excel-файл с банковскими операциями.
По умолчанию проект использует файл: data/operations.xlsx

5. Запустить приложение
```
python main.py
```

## Пользовательские настройки

Файл user_settings.json содержит настройки пользователя: список валют и акций, по которым приложение получает дополнительную финансовую информацию.

Пример структуры:
```
{
  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "AMZN", "GOOGL"]
}
```

## Использование:
1. В директории *./data* находится файл **operations.xlsx**, содержащий 
информацию о банковских операциях. Вы можете заменить этот файл 
собственным с аналогичной структурой и форматом данных. 
2. В корневой директории расположен файл **user_settings.json**, 
содержащий информацию об интересующих пользователя валютах 
и акциях. Вы можете заменить этот файл собственным с аналогичной
структурой и форматом данных. 
3. Если Вы хотите разместить exel файл или json-файл в другой 
директории или если эти файлы имеют иное название, обратитесь к 
модулю **config.py** в корне проекта и настройте путь до 
нового файла.
4. В модуле **main.py** в корне проекта находится функция, запускающая
программу с пользовательским интерфейсом, запрашивающая ввод
информации от пользователя, на основании которой будут формироваться 
массивы данных.

## Основные модули
### src/views.py

Содержит функции для формирования данных главной страницы:

- приветствие;
- информация по картам;
- топ транзакций;
- курсы валют;
- стоимость акций.

### src/reports.py

Содержит функции для формирования отчётов, например отчёта по тратам в определённой категории за последние 3 месяца.

### src/services.py

Содержит дополнительные сервисные функции, например поиск переводов физическим лицам по шаблону в описании операции.

### src/utils.py

Содержит вспомогательные функции:

- чтение Excel-файла;
- обработка данных;
- работа с пользовательскими настройками;
- запросы к внешним API;
- подготовка данных для отчётов.

## Тестирование

Для запуска тестов используется pytest.
```
pytest
```
Для запуска тестов с отчётом о покрытии:
```
pytest --cov=src --cov-report=html
```
HTML-отчёт будет сформирован в директории:
```
htmlcov/
```
## Логирование

Базовые настройки логирования находятся в файле logging.ini в
корне проекта. Логи создаются и сохраняются в папке /logs в 
корне проекта.
